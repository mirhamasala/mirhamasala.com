## Ingredients

### Sauce

| Amount | Ingredient             |
| ------ | ---------------------- |
| 3      | garlic cloves, chopped |
| 1      | onion, chopped         |
| 1      | carrot, chopped        |
|        | fresh parsley          |
| 1      | clove (spice)          |
| 1      | bay leaf               |
|        | pepper                 |
|        | Vegeta seasoning       |
|        | oil                    |
|        | paprika powder         |
|        | tomato puree           |
| 200 ml | water                  |

### Filling and vegetables

| Amount | Ingredient                                                                                      |
| ------ | ----------------------------------------------------------------------------------------------- |
| 2      | courgettes, peeled and scooped out (or 500 g onions, peeled and parboiled in water and vinegar) |
|        | vinegar, for parboiling onions, if using                                                        |
| 300 g  | minced meat                                                                                     |
| 60 ml  | rice, measured by volume                                                                        |
| 1      | small onion, finely chopped                                                                     |
| 1      | garlic clove, finely chopped                                                                    |
| 1      | carrot, finely grated                                                                           |
|        | fresh parsley, chopped                                                                          |
|        | oil                                                                                             |
|        | Vegeta seasoning                                                                                |

### Roux (zaprska)

| Amount | Ingredient  |
| ------ | ----------- |
| 1 tbsp | plain flour |
|        | oil         |

## Method

1. Make the sauce: chop the garlic, onion, carrot and parsley and saute in oil. Add the herbs, spices and tomato puree. Add the water. Set aside.
2. Mix together the minced meat, rice, onion, garlic, carrot, parsley, oil and Vegeta to make the filling.
3. If using courgettes: hollow them out, leaving the base intact. Do not scoop all the way to the bottom.
4. If using onions: peel and parboil in water with a splash of vinegar until softened enough to separate into layers.
5. Fill the courgettes or onion cups with the meat and rice mixture, leaving room for the rice to expand.
6. Arrange in a pot in a single layer and pour the sauce over to partially cover. Add more water as needed.
7. Cover and cook on low heat. After about 40 minutes, make the roux: fry the flour in a little oil, then stir into the pot to thicken the sauce slightly.
8. Continue cooking until the meat is fully cooked and the rice is tender.

## Notes

- Vegeta is a common Balkan all-purpose seasoning blend.
- This dish can be made with either courgettes (tikvice) or onions (luk) - or both.
